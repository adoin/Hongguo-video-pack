状态定义：

- **实测有效**：读到并核对了业务数据；媒体另需下载和解码验证。
- **程序已验证**：自研请求或解析已通过相应验证，不代表已在发行版启用。
- **已观测**：抓到路径或请求，但尚未核对全部响应字段。
- **参考实现**：在其他程序源码找到，未在本项目中复验；参考程序测试不能当成本项目实测。
- **失败/限制**：空正文、重复页、无效身份、非零业务码或未完成验收。

所有示例均为结构示例。`<...>` 是占位符，不能直接发送。设备/安装标识、Cookie、签名值、证书私钥、媒体解密材料及带签名临时 URL 不进入本目录。原始记录在被忽略的 `.local/`，不随源码包、安装包分发。

本目录属于接口参考，产品行为仍以 [产品契约](../notes/active/hongguo-studio.md)、[搜索契约](../notes/active/search-and-source-integration.md) 和 [禁止方案](../notes/prohibited/search-fallbacks.md) 为准。新增证据应更新对应接口的验证状态，不能把“参考实现”直接改写为“已成功”。
