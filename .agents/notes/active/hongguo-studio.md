# 红果工坊产品与交付契约

## 项目目的

用一套 Flutter / Dart 代码维护 Windows 桌面端和安卓端，完成选剧、读取完整分集、选择来源实际可用画质、下载、兼容与合集导出。桌面应用提供安装交付，手机界面可独立操作。

## 确认契约与验收口径（对原话的实施解释）

- Windows / Android 共用界面、领域模型和任务编排；平台桥接承担签名、系统文件保存和桌面窗口控制。
- Borderless：卡片无边框，靠 shadow + gap 组织布局；桌面侧栏、移动底部导航清晰区分发现、工作台和任务。
- 桌面版本号固定放在左侧深色导航条底部，点击进入关于与许可，并提供直接检查更新按钮；移动端顶部紧凑工具栏显示应用名、可点击版本和检查更新入口。关于与许可保留第三方声明。2026-11-02 用户明确选择保留 GPL 并调整原“严禁任何商用”提示：软件源码依 GPL-3.0 发布，内容提示针对未经授权下载、传播或商业利用视频；必须区分软件许可与视频内容授权，不恢复对软件本身的笼统禁商用声明。
- 示例工作单元为《持械入宋：第一季》与上述播放页。剧库卡片的预览分集不能当作完整分集，进入工作台后必须重新读取完整列表。
- 画质只能来自来源真实返回并经引擎支持的资源。原始登录要求保留，但来源实际观测已证实访客也可能拿到 1080P；不得伪造登录、虚构清晰度或把访客能力误称已完成官方登录。
- 支持按集选择、范围选择、顺序下载、本地素材导入与排序、取消、失败重试、完成分集缓存复用、导出记录持久化。
- 同规格优先复制原流。纯尺寸差异取最多出现的规格，保持比例缩放 / 补黑，优先只处理差异集数；混合拼接必须校验兼容性并完整解码。失败才允许明确回退全量统一编码。
- 默认约束资源：编码和解码线程最多 2，滤镜线程 1；HEVC 编码限制线程池。线程预算不能表述成固定 CPU 百分比上限，独立进程或系统 CPU 硬配额尚不能声称已实现。
- 缓存清理只清应用拥有的下载缓存，保留成品；取消和失败不能误标成功。未完成分集可重下，不能把完整分集复用称为字节级断点续传。
- Windows 主要交付为安装程序，含目录选择、开始菜单、可选桌面图标、卸载；不强制终止现有任务，卸载不删用户设置与导出。便携包只能作备用交付。
- Linux / macOS 如纳入支持范围，同样须提供对应安装格式及验证；不能把 Windows 安装包冒充跨系统包，也不能宣称尚无构建的系统已受支持。
- Android 成品先存应用内，再通过系统选择器另存；必须区分构建成功、模拟器检查和真实设备验收。
- 随交付提供对应源码和许可证；协议适配及 FFmpeg 的 GPL 来源声明不能删掉。

## 稳定架构与源路径

- `lib/main.dart`：主题、无边框窗口、响应式导航、工作台与任务界面。
- `lib/app_controller.dart`：设置恢复、选择、下载编排、缓存、取消与历史。
- `lib/domain/drama.dart`：剧集、分集和实际画质模型。
- `lib/data/hongguo_client.dart`、`media_crypto.dart`、`request_signer.dart`：来源详情、取流、媒体解析和签名桥接。
- `lib/services/media_engine.dart`：原生 FFmpeg、探测、限线程、同规格拼接、差异修复及校验。
- `assets/protocol/`、`android/app/src/main/kotlin/dev/hongguo/hongguo_studio/protocol/`：Windows / Android 签名适配。
- `lib/data/discovery_client.dart`、`lib/discovery_controller.dart`、`lib/discovery_view.dart`：剧库与搜索，契约见 [搜索规格](search-and-source-integration.md)。
- `installer/windows.iss`、`scripts/package.ps1`、`scripts/build-installer.ps1`、`scripts/test-installer.ps1`：Windows 交付和安装 / 卸载验证。
- `docs/acceptance.md` 及带版本号的历史验收文档保存验证边界；不能把历史验收当作新功能已验收。

## 已批准但尚未完成的项目目标

- 接通真实来源搜索的后续分页，并在 Windows 与 Android 一致工作，见搜索规格。
- 完善关联漫剧 / 同系列识别依据；同名推断必须标明，不能冒充官方关联。
- 依据真实来源能力实现账户登录与授权画质，或取得用户明确的范围变更；访客取流不等于登录能力完成。
- 完成自研 Android 应用的设备级安装、系统文件保存、前台服务、长任务和热管理验收；仅安装官方红果不构成这些项目的验收。
- 对完整长剧任务验证尺寸差异、取消、失败恢复、输出音画和资源占用；小样本通过不能代表完整 100 集已验证。
